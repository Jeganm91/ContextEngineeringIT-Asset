# Premium Print Plan — Service Tier Overview

Facilities offers a Premium Print Plan for high-volume office printers. The premium
tier covers priority toner replacement, same-day technician dispatch, and an
expedited approval path for consumables cost recovery when a print job exceeds the
standard department quota.

Requesting the premium print tier requires manager approval and, for departments
already over their quarterly print budget, additional approval from the Procurement
Lead before the premium cost is applied. The monthly premium print surcharge is
recovered automatically through the department's facilities cost center — no
separate expense claim is needed.

This plan concerns printer hardware service levels only. It does not apply to
software licensing, software cost recovery, or any subscription-based application
spend; those are governed by the IT Asset Management team's separate license and
premium-software approval policies.

# Software License Request Process

Employees submit requests through the Software Request Portal with Employee ID,
software name, business justification, and requested duration.

Manager approval is required within 5 business days. Premium software (per-seat
cost) additionally requires Procurement Lead approval for budget, seat count and
cost center.

Provisioning completes within 2 business days of full approval. Premium license
utilization is reviewed for renewal every 12 months.

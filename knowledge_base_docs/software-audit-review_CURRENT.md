# Software Audit and Compliance Review Process

IT Asset Management conducts a quarterly software audit to verify that
installed applications match approved licenses. Cost review during the audit
covers license utilization, seat count accuracy, and vendor contract renewal
dates.

Employees found using unapproved software are required to either remove it
or submit a formal request through the standard licensing process. This
review does not cover personal expense claims of any kind.

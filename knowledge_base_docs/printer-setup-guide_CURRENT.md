# Office Printer Setup Guide

Connect to shared office printers via Settings > Printers > Add Printer,
selecting the printer nearest your desk from the list. Enter your network
credentials when prompted, then print a test page to confirm the connection.

For toner or paper jam issues, submit a facilities ticket rather than an IT
software ticket.
